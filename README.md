# NaBFID Offense Processor

A browser-based workspace for preparing daily offense reports. This repository currently contains a temporary project landing page; offense processing is not implemented yet.

## Current structure

- `index.html` — semantic page structure
- `css/style.css` — responsive visual design
- `js/app.js` — small ES module entry point

## Planned implementation

The application will use modular JavaScript and SheetJS for Excel import/export. Processing will be performed in the browser where practical, and report logic will be kept separate from the UI.

## Preview

Open `index.html` through VS Code Web or publish the repository using an approved static hosting option. The page references Google Fonts for Inter; the browser will fall back to system fonts if that service is unavailable.

> This is a temporary landing page. Upload, reconciliation, and report-generation features are not available yet.
